# Тренажери для учнів

Десять тренажерів і 257 рівнів, які працюють просто в браузері: без встановлення, без реєстрації й без сервера. Статичні сторінки: HTML, CSS і модулі JavaScript, нічого не треба збирати.

| Сторінка | Що це | Рівнів |
|---|---|---|
| `index.html` | Головна: показує всі тренажери за темами | — |
| `mouse-trainer.html` | Мишка й точність: клацання, перетягування, виділення рамкою, прокручування | 24 |
| `files-trainer.html` | Файли й папки: шляхи, імена й розширення, кошик, пошук | 24 |
| `safety-trainer.html` | Безпека в інтернеті: адреси сайтів, фішинг, паролі, особисті дані | 20 |
| `hotkeys-trainer.html` | Гарячі клавіші для тексту, браузера й Windows | 20 |
| `typing-trainer.html` | Сліпий друк: українська й англійська розкладки | 51 |
| `robot.html` | Алгоритми з роботом: команди, цикли й умови блоками | 24 |
| `network-trainer.html` | Мережі: кабелі, IP-адреси, роутер, DNS, DHCP, ping | 20 |
| `uiux-trainer.html` | UI/UX-дизайнер: знайти й виправити помилки екрана | 20 |
| `pen-trainer.html` | Тренажер пера, як у Figma й Illustrator | 26 |
| `color-trainer.html` | Колір на око: відтінок, насиченість, змішування світла | 28 |

## Запуск

```sh
npm start            # http://localhost:8080
npm test             # модульні тести
npm run test:e2e     # тести в браузері (потрібен Playwright)
```

## GitHub Pages

Settings → Pages → Deploy from a branch → `main`, `/ (root)`. Усі шляхи відносні, тож сайт працює й у підпапці.

Прогрес і зірки зберігаються лише в браузері (localStorage).
